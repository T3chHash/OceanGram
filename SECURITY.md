# Security Policy

## Supported Versions

We provide security updates and patches for the current release branch.

## Reporting a Vulnerability

The Songbird team takes security seriously. If you discover a vulnerability or potential security flaw, please report it responsibly so we can address it before public disclosure.

**Please do not report security vulnerabilities via public GitHub issues, discussions, or pull requests.**

### Preferred Method: GitHub Private Vulnerability Reporting

You can privately report a vulnerability directly on GitHub:

1. Go to the [Security Advisories](https://github.com/bllackbull/songbird/security/advisories/new) page.
2. Click **Report a vulnerability**.
3. Fill out the report form with full reproduction details.

### Alternative Method: Email

If you prefer email or cannot use GitHub Advisories, contact the maintainer directly:

* **Email:** [pouyakhalili83@gmail.com](mailto:pouyakhalili83@gmail.com)
* **Subject:** `[Songbird Security] <Summary of issue>`

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:

* A description of the vulnerability and its potential impact.
* Step-by-step instructions or proof-of-concept code to reproduce the issue.
* Affected components (e.g. server API, client SPA, media worker, authentication, database).
* Suggested mitigations or patches if available.

### Response Timeline

* **Acknowledgment:** Within 48 hours of receiving the report.
* **Triage & Assessment:** Initial assessment of severity and validity within 5 business days.
* **Resolution & Patch:** We will work on a fix in a private advisory and release a patched version as soon as possible.
* **Disclosure:** Once the patch is available, we will publicly publish a security advisory giving appropriate credit to the reporter (unless you request anonymity).
